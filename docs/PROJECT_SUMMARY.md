# pet925 プロジェクト・サマリー

## 🏆 到達レベル
**実戦的な開発現場で通用する「ジュニア〜ミドルエンド級エンジニア」**
単にコードを書くだけでなく、運用の効率化、データの安全性、自動化を統合して設計・構築できるレベルに到達しています。

## 🛠 習得・活用した技術
1. **データ駆動型アーキテクチャ (Data-Driven)**
   - 人間が編集する「マスターデータ(.ods)」と、プログラム用の「中間データ(.csv)」、Web用の「配信データ(.js)」を分離するプロの設計思想。
2. **静的サイト生成 (SSG) と自動化**
   - Node.js を使ったビルドパイプラインの構築。
   - `fs.watch` によるファイル変更の自動検知（監視モード）。
3. **データ品質管理 (QA)**
   - 正規表現（Regex）を駆使した高度な CSV パース処理。
   - 許可タグリストに基づく自動バリデーション（入力ミス検知）。
   - **Jest** による自動ユニットテストの導入。
4. **モダン・フロントエンド**
   - Vanilla JS によるデータ駆動の UI 生成。
   - 複数ショップの価格比較アルゴリズムと「最安値」自動判定。
   - CSS Grid/Flexbox や Backdrop-filter を使ったカタログ風デザイン。

## 📝 実施内容の記録

### 1. データ管理の革新
- **統合マスターファイル (Unified Master)**: `products`, `tags`, `brands` を一つの `.ods` 内でシート別に管理。マクロによる一括CSV出力により、運用のヒューマンエラーを完全に排除。
- **アフィリエイト・価格連携**: A8.net、Amazon、楽天、Yahoo!の価格比較列を追加し、収益化の基盤を作成。

### 2. 検索・フィルタリングの高度化（New）
- **「製法・原材料」グループの確立**: 「穀物不使用」や「ラム」「魚」を独立させ、ユーザーが本当に求める条件をクイックに選択可能に。
- **エイリアス機能（自動タグ付け）**: サーモンやマグロといった具体的な魚種から、自動で「魚」フィルタを有効にするスマートロジックを搭載。
- **日本語検索の正規化と検索精度の最適化**: ひらがな・カタカナの区別を無くし、検索対象を「商品名」と「ブランド名」に絞り込むことで、ノイズの少ない的確な検索体験を実現。
- **複数選択（マルチセレクト）と絞り込みの深化**: 「製法・原材料」「お悩み」グループで複数のタグを同時に選択可能。チェックを入れるほど条件が限定される**AND検索ロジック**を採用し、ユーザーが求める「究極の一皿」に辿り着きやすい設計に改善。
- **タグ構成の最適化**: 運用に合わせて「ドライ」タグを廃止するなど、ユーザーの選択肢を常に最適化。

### 3. システムのインテグレーション
- **変換スクリプト (`convert.js`)**: CSVを高速に JS へ変換する心臓部を開発。
- **監視モードとデバウンス処理**: 保存するだけで即座に反映される環境に加え、連続保存による多重実行を防ぐ待機ロジック（Debounce）を搭載。
- **タグマスターの外部化 (`tags.csv`)**: フィルターのカテゴリや表示名を外部ファイルで管理。プログラムを修正することなく、スプレッドシートの操作のみでサイト構成の変更が可能に。
- **ブランドエイリアスの外部化 (`brands.csv`)**: 英語ブランド名と日本語検索ワードの紐付けを外部化し、検索の柔軟性を向上。
- **タグの一元管理**: 1箇所の修正で「チェック機能」と「サイトのボタン」が連動する仕組み。

### 4. ユーザー体験 (UX) の向上
- **商品名・ブランド検索**: ユーザーが探している特定の商品やメーカーを素早く見つけられるよう、検索窓の役割を最適化。
- **インタラクティブ・ナビ**: フィルタパネルにマウスドラッグによる横スクロール機能を実装し、操作性を向上。
- **自動リンク生成**: 個別URLがない場合も、商品名で各モールの「安い順検索」へ自動誘導。
- **最安値バッジ**: 3モールの価格から自動で最も安いショップを強調表示。
- **画像フォールバック**: 画像未設定やエラー時にデフォルト画像を表示する、リンク切れを恐れない堅牢なフロントエンド。
- **エラー画面の親切化**: 検索結果が0件の際のおしゃれなメッセージ表示。

### 5. 運用のプロフェッショナル化
- **詳細なマニュアル (`MANUAL.md`)**: タグリスト、運用ルーチン、トラブル対処法を完備。
- **プロジェクトドキュメント (`README.md`)**: プロジェクトの目的やAIへの指示書を整理。
- **テストコード (`convert.test.js`)**: ロジックが壊れていないか機械が証明する仕組み。

## 🤖 今後の AI への指示用テンプレート
Gemini に相談する際は、以下をコピーして渡すとスムーズです。

> **プロジェクト背景:**
> 14列構成のCSVから `data.js` を生成し、`index.html` で動的表示するペットフード比較サイト。
> **現在の構成:**
> - `pet925_master.ods` (3シート構成) が唯一の真実、3つのCSVが自動生成される中間ファイル。
> - `convert.js` が監視・変換・バリデーションを担当。
> - `index.html` がタグ生成・価格比較・描画を担当。
> **ルール:**
> - タグは `tags.csv` に定義されている `key` のみを使用する。
> - 列構成：`name,brand,tags,desc,size,img,amz,rak,yah,a8,label,promo,amz_p,rak_p,yah_p`
