# pet925 | Premium Pet Nutrition Guide

科学的な根拠に基づいたプレミアムペットフードの選定ガイドシステムです。
スプレッドシート（マスターデータ）からWebサイトを自動生成する仕組みを構築しています。

## 🚀 プロジェクトの目的 (Objective)
- 複雑なペットフードのデータをミスなく、楽に管理する。
- A8.netやAmazon等のアフィリエイト報酬を最大化する「最安値比較機能」の提供。
- AI（Gemini）を開発パートナーとして、爆速でコンテンツを拡充する。

## 📂 構成ファイル (Context)
### 📂 Directory Structure
- **`src/`** : `convert.js` (変換プログラム), `convert.test.js` (テスト)
- **`data/`** : `pet925_master.ods` (4シート構成のマスター), `products.csv` (中間データ)
- **`index.html`** : サイト本体（ルート配置により公開を簡素化）
- **`data.js`** : 変換プログラムから出力される配信データ
- **`docs/`** : `MANUAL.md` (運用手順書), `PROJECT_SUMMARY.md` (開発記録)
- **`README.md`** : プロジェクトの全体概要（このファイル）

## 🛠 開発者コマンド
```bash
# 1. 依存関係のインストール
npm install

# 2. 監視モード（保存するだけで自動更新）
npm start

# 3. テストの実行
npm test   # 変換ロジックが壊れていないか自動チェック（デプロイ前に推奨）

# 4. データの公開（デプロイ）
npm run deploy   # データの保存、コミット、プッシュを一括実行

# 5. 強制同期（競合等でプッシュできない場合）
git push origin main --force
```
